# Missing detail vs reference

**Symptom.** The model is the right object but lacks the details that make it this one (hilt shape, engravings, brickwork).

**Cause.** Working from a description instead of the reference image.

**Fix.** Ask for the reference; list the 3-5 details that identify it and check each.
